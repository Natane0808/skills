# kuikly-pitfalls

KuiklyUI 实战踩坑手册 —— 由一个真实项目（稻香匣，Kuikly 2.30.0 / Android）积累。

## 这是什么

官方技能（`kuikly-ui-framework` 等）讲**怎么用**；这个技能讲**哪里会翻车、怎么快速定位**。

所有条目都满足三个条件才收录：
1. **在真实项目里踩过**；
2. **有源码依据或真机取证**（截图 / 逐像素采样）；
3. **给出了正确写法**。

没有实测证据的，一律不写（宁可缺失，不要误导）。

## 收录内容

13 类坑，按"症状"索引：

| 症状 | 根因 |
| --- | --- |
| 布局左右不对称 | `Scroller` 上写了 padding |
| 数据变了 UI 不变 | 创建期读快照（断订阅） |
| 列表能展开但空 | `forEach` 渲染列表 |
| 动画完全不动 / 播一下停 | `forEach` 订阅未建立 / `repeatForever` 被杀 |
| 阴影变成实心色块 | `BoxShadow` 缺 `fill=false` |
| 阴影完全看不到 | `offsetX/Y` 都是 0 |
| 描边粗 3 倍 / 消失 | 描边宽度被取整成整数物理像素 |
| 渐变画成纯色 | 渐变端点退化成 `(0,0)→(0,0)` |
| 编译报接收者无法解析 | `View {}` 的 lambda 不是 `ViewContainer` |
| 输入框每敲一个字触发 | 输入法组字期也会触发 `textDidChange` |
| RichText 铺不满 | 不响应 `alignItemsStretch()` |
| 构建 dexing 崩溃 | AGP 与 Kotlin 版本不匹配 |
| SVG 加载不出来 | Kuikly 只认位图 |

## 最有价值的三个结论

**① 创建期读快照 = 断订阅**
Kuikly 在 `attr{}` 执行期读取 observable 时建立订阅。创建期读走的值之后不会更新，**而且不报错、不警告**。三种表现：`forEach` 渲染列表为空、动画不启动、把值算成 String 传给普通函数后永不刷新。

**② `repeatForever` 在 Android 上必被杀**
不是"不生效"，是架构级冲突：无限动画永不结束 → 动画计数恒 ≥1 → `isPlaying()` 恒 true → 每轮 `attr{}` 结束都被 `cancelAnimation()` 取消。

**③ 描边宽度会被四舍五入成整数物理像素**
`1f` 在 2.75 密度下变成 **3** 个物理像素。CSS 的 `1px` 应对应 Kuikly 的 `0.5f`。

## 一条通用原则

> **凡是源码看起来正确、但实测不生效的 API，一律以实测为准并登记。**
>
> `repeatForever` 的源码设了 `ObjectAnimator.INFINITE`，端侧却不生效。只看源码会让你以为是自己的调用方式错了。
